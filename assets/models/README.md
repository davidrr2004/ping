# TensorFlow Lite Models

This folder should contain the following 5 TensorFlow Lite models:

1. **noise_suppressor.tflite** - Noise suppression model
2. **yamnet.tflite** - Sound classification model (runs continuously)
3. **vad.tflite** - Voice Activity Detection model
4. **whisper.tflite** - Speech transcription model
5. **urgency_cnn.tflite** - Urgency analysis model

These models are used in the audio processing pipeline to provide real-time audio analysis and transcription.
